# Stable-noise numerical checks

Reproducible numerical checks for stable-noise fluctuations.

## Install

```bash
python -m pip install -r requirements.txt
```

## Figures

```bash
python figures.py --outdir figures
```

Use `--quick` for a faster run.

## Extended checks

```bash
python experiments.py --outdir outputs --strict
```

Use `--quick` for a faster test.
